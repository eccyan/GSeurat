Four Pipeline Stages

1. ZoneResolver

Test player position against all volumes (AABB/Sphere contains). Check explicit triggers for enter/exit events. Resolve priority (smallest volume or manual). Output: which zone(s) are active, any pending transition.

2. VCamEvaluator

For each active zone, compute the ideal camera state based on its mode: orbit (spherical coords), rail (spline evaluate), fixed point, side-scroll, or cinematic. Apply spring damper for target tracking. Output: one CameraState per active zone.

3. CameraBlender

If transitioning between zones, smoothstep-blend between VCam outputs over blend_time. Position: lerp. Rotation: slerp. FoV: lerp. If not transitioning, pass through the single active VCam state. Output: one blended CameraState.

4. ConstraintClamp

Final safety pass. Clamp position inside active volume boundaries. Clamp pitch/yaw to authored limits. This is the "hard wall" — even if blending overshoots, the camera never escapes the valid region. Output: final CameraState → view/proj matrices.

Key Data Types

// Output of the entire pipeline — what the renderer consumes
struct CameraState {
    glm::vec3 position;
    glm::vec3 target;
    glm::vec3 up = {0, 1, 0};
    float fov = 45.0f;
};

// Per-zone camera behavior configuration
struct CameraParams {
    CameraMode mode;         // free_look | rail_follow | cinematic_rail | fixed_point | side_scroll
    int priority = 0;        // 0 = auto (smallest volume wins), >0 = manual
    float blend_time = 1.0f; // seconds for smoothstep transition into this zone
    bool free_look = true;   // player can orbit camera
    float pitch_min = -60.f; // degrees
    float pitch_max = 10.f;
    float yaw_min = -180.f;
    float yaw_max = 180.f;
    float fov = 45.0f;
    std::string rail_id;     // references a CameraRail by id (for rail modes)
    glm::vec3 fixed_position;// for fixed_point mode
    glm::vec3 offset = {0, 5, -10}; // camera offset from player (free_look/side_scroll)
};

// Volume entity (ECS component, trivially copyable)
struct CameraVolume {
    VolumeShape shape;       // std::variant<AABB, Sphere>
    CameraParams params;
};

// Explicit trigger (ECS component)
struct CameraTrigger {
    VolumeShape shape;       // thin AABB or sphere at doorways
    std::string from_zone;   // optional: only fire from this direction
    std::string to_zone;     // target zone to activate
    float blend_override = -1; // -1 = use target zone's blend_time
};

// Spline rail (shared data, not per-entity)
struct CameraRail {
    std::string id;
    SplinePath path;         // existing Catmull-Rom (gs_spline.hpp)
    SplinePath target_path;  // optional: where camera looks along the rail
};
